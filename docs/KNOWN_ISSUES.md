# Known issues and open questions

- **The game packages cannot be decrypted yet.** The base game and add-on packages need the license data for the
  title, which has not been supplied. It is not yet known whether the update package's executable can be decrypted
  without that license.
- **Unknown until the game can be analyzed:** the game engine, asset formats, which audio library the game uses, and
  where rhythm timing comes from.
- **Linux has not been built.** It is covered only by psvrecore's CI, which runs once the repositories are pushed.
